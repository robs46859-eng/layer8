02 · Division of responsibility

One governed envelope. Two explicit control layers.

Layer8 owns secure execution and operational policy. The SALTI-B Engine owns adaptive workflow control. Keeping those boundaries visible makes the system easier to audit, test, and trust.

L8 / 01

Layer8 Adaptive

The operational substrate

Governs who may request work, where it runs, and how each decision is recorded.

  • Identity, tenancy, policy, and scoped access
  • Multi-provider model routing and failover
  • Usage, cost, versioning, and rate enforcement
  • Structured audit records and evidence references
SB / 02

SALTI-B Engine

The adaptive controller

Governs exploration, condition, repair, confidence, and accountable release.

  • Durable specialist-agent cascade control
  • Adaptive, bounded, reason-coded repair
  • Weakest-link validation and acceptance gates
  • Human review when evidence or consequence demands it

03 · SALTI-B control sequence

Generation is a step—not a verdict.

Specialist stages turn an open-ended model response into a bounded, inspectable execution. Failure is routed, not hidden.

SALTI-B Engine · Cascade gatesSheet 01 / 01
  1. 01GroundAccept context

    Fix the evidence baseline before exploration begins.

  2. 02ExploreGenerate diversity

    Route work across models without confusing variety for quality.

  3. 03ValidateApply gates

    Test every critical channel; one failed channel can hold the run.

  4. 04RepairBound attempts

    Make reason-coded corrections, cap retries, and validate again.

  5. 05CalibrateMeasure confidence

    Separate heuristic condition from calibrated operational confidence.

  6. 06ApproveRelease or review

    Route consequential or uncertain work to accountable humans.

04 · Why the loop has to close

Open-loop AI ships plausible defects.

When one model both generates the work and approves it, failure is silent — the output looks right, passes casual review, and surfaces later as a defect. Closing the loop separates exploration, validation, and reason-routed repair so a failed check holds the run instead of shipping it.
